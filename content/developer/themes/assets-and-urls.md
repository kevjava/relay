---
title: Theme Assets and URLs
---

Relay can run at a domain root or in a subdirectory. Every local URL generated by a PHP template must use `url_base()` so the active deployment path is included.

## Organize Local Assets

Asset directories are optional conventions. A self-contained theme might use:

```text
themes/my-theme/
├── css/
│   └── theme.css
├── js/
│   └── theme.js
├── img/
│   └── wordmark.svg
└── fonts/
    └── body.woff2
```

Keep runtime assets inside the theme unless you intentionally depend on a documented Relay core asset. Use versioned or content-hashed filenames when long cache lifetimes are important.

## Use `url_base()`

Generate local asset and route URLs in PHP:

```html
<link rel="stylesheet" href="<?php echo url_base('/themes/my-theme/css/theme.css'); ?>">
<script src="<?php echo url_base('/themes/my-theme/js/theme.js'); ?>"></script>
<img src="<?php echo url_base('/themes/my-theme/img/wordmark.svg'); ?>" alt="My Relay Site">
<a href="<?php echo url_base('/about'); ?>">About</a>
<a href="<?php echo url_base('/'); ?>">Home</a>
```

Given `url_base('/themes/my-theme/css/theme.css')`, Relay produces:

| Deployment | Result |
| --- | --- |
| Domain root | `/themes/my-theme/css/theme.css` |
| `/relay/` subdirectory | `/relay/themes/my-theme/css/theme.css` |

A literal root-relative URL such as `/themes/my-theme/css/theme.css` bypasses Relay's detected base path and fails when the site is mounted below `/`.

Escape dynamically assembled URLs before placing them in an HTML attribute:

```html
<?php $logo_url = url_base('/themes/my-theme/img/' . $metadata['logo']); ?>
<img src="<?php echo htmlspecialchars($logo_url, ENT_QUOTES, 'UTF-8'); ?>" alt="">
```

Prefer fixed theme-owned filenames. If metadata selects an asset, validate it against an allowlist before constructing the URL.

## Reference Theme Files Carefully

Relay does not currently expose a helper that derives the active theme's public asset URL. A distributable theme therefore uses its own stable directory name in URLs, such as `/themes/my-theme/...`. Renaming that directory requires updating these references.

Do not turn filesystem paths from `theme_get_active_dir()` into public URLs. Filesystem and web paths are different concerns, especially behind proxies or in containers.

## CSS and Fonts

Keep CSS references relative when one theme asset refers to another:

```css
@font-face {
    font-family: "My Theme Serif";
    src: url("../fonts/body.woff2") format("woff2");
    font-display: swap;
}

.site-logo {
    background-image: url("../img/wordmark.svg");
}
```

The browser resolves these against the stylesheet URL, so Relay's base path remains intact.

Test asset loading both at `/` and at a path such as `/relay/`. Then learn how to [render and customize navigation](navigation).
